# Maple (Family Assistant / Organizer) — Complaint Research

## Overview

Maple Family Assistant (by Grow Maple Inc. / MWM, App Store id 1551070188) is an AI-assisted all-in-one family organizer: shared calendar, a "family email inbox" that turns emails into tasks, to-do lists, chore tracker, meal planner, grocery lists, shared notes, and a built-in "Maple Assistant." Free tier plus a subscription for premium features (exact price not confirmed — third-party trackers note recently-added paywalls on previously free features). App Store aggregate shown by a third-party tracker: 4.3/5 from ~1.2K ratings (not independently verified against Apple's live page in this pass). Direct App Store RSS review feed returned no entries in either the US or UK store at time of research (low review volume relative to rating count, or feed pagination limits) — findings below are drawn from WebSearch-aggregated third-party summaries, flagged as **paraphrased, not verbatim**.

Strengths: closest AI-assistant positioning to Kinrows' Concierge (email-to-task conversion, "Maple Assistant" auto-organizing); broad feature breadth (calendar + email + chores + meal planning + notes) in one app, similar footprint to Kinrows' "everything in one place" pitch.

## Complaint clusters

### 1. New paywalls on previously-free features
- **Problem:** Users report Maple moved features that used to be free behind a subscription.
- **Evidence (paraphrased via WebSearch aggregation, accessed 2026-09-15):** *"Recent updates introducing subscription models for previously free features, along with persistent bugs, performance issues, and a lack of widgets, have led to significant user frustration."*
- **User type:** Existing free users who onboarded the household expecting a stable feature set.
- **Intent:** Complaint / trust erosion → alternative search.
- **Related Kinrows capability:** Kinrows' core app (calendar, lists, pantry, budget, cook, trips, decisions, routines, chores, care, notes, messages) is free permanently; only the optional Concierge AI layer is paid — a direct contrast to "features got paywalled after I was already in."
- **Candidate page type:** "Maple app alternatives" / "free family organizer apps (that stay free)."
- **Conversion potential:** High — bait-and-switch pricing is a strong trust/switching trigger.

### 2. Setup friction / data loss, confusing interface
- **Problem:** Users report spending significant time setting up calendars/onboarding only to have data or configuration disappear, and describe the interface as non-intuitive with no customization.
- **Evidence (paraphrased, accessed 2026-09-15):** *"Users report spending hours setting up calendars despite a non-user-friendly interface, only to have everything disappear, finding it confusing to use with no customization."*
- **User type:** New households trying to onboard everyone.
- **Intent:** Onboarding frustration.
- **Related Kinrows capability:** Two-way phone-calendar sync (bring in existing events rather than manual re-entry); FLScreenHeader-led, single design-system onboarding intended to reduce setup friction.
- **Candidate page type:** "How to set up a family calendar app without losing your data" / onboarding-focused comparison.
- **Conversion potential:** Medium.

### 3. Bugs / performance issues, missing widgets
- **Problem:** General instability ("glitchy and buggy behavior") and a persistent lack of home-screen/lock-screen widgets.
- **Evidence (paraphrased, accessed 2026-09-15):** *"Some users experience glitchy and buggy behavior."* Lack of widgets specifically called out as a gap.
- **User type:** Daily-driver users wanting at-a-glance info without opening the app.
- **Intent:** Feature-request / reliability complaint.
- **Related Kinrows capability:** none confirmed — Kinrows widget support not verified in this research pass; flag as a possible gap to check against actual iOS feature set before using in marketing copy.
- **Candidate page type:** N/A dedicated; fold into general reliability content.
- **Conversion potential:** Low-medium.
