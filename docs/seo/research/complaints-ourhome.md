# OurHome — Complaint Research

## Overview

OurHome (classic "OurHome: chores and rewards", originally by BecomingMom Inc.) is a free chores-and-allowance app for families: assign chores, points/rewards, shared shopping lists, meal planning, and a family calendar. Free with no stated paid tier found. **Status note (important for content angles):** the original OurHome App Store listing (id 879717020) no longer resolves via the App Store lookup API (0 results) — third-party trackers describe it as effectively abandonware ("no updates recorded since 2022," per a competitor comparison page at choresplit.com/compare/ourhome), while its Google Play listing (com.elusios.ourhome, a 2025-era relaunch by "Elusios") shows a much lower 3.1/5 from ~4,510 reviews. A separate, unrelated "OurHome by Elusios" app (id 6753957205, 4.1★) also exists on the App Store — naming confusion between the old and new apps is itself a user complaint vector. Strengths repeatedly cited: it's free, combines chores + shopping + calendar in one place, and (in its heyday) was praised as an "App of the Week" pick for simple gamified chore tracking.

Could not retrieve verbatim App Store 1–2★ review text directly (listing delisted / RSS empty); findings below are drawn from secondary sources (ChoreSplit comparison page, WebSearch aggregation) — flagged as **paraphrased, not verbatim** where noted.

## Complaint clusters

### 1. App abandoned / stopped receiving updates
- **Problem:** Users report the app has gone stale — "no updates recorded since 2022," no bug fixes, no communication from the developer.
- **Evidence:** Paraphrased from https://choresplit.com/compare/ourhome (accessed 2026-09-15): *"no updates recorded since 2022"*; the site notes it deliberately removed previously-cited "app-store star ratings, dated user reviews and specific bug reports that had no source of record."
- **User type:** Parents who already onboarded the whole family and don't want to migrate.
- **Intent:** Comparison / "alternatives to" (switching intent).
- **Related Kinrows capability:** Actively maintained app with chores/allowance (age-banded 2–3/4–5/6–8/9–12/13+ program) plus calendar/lists/pantry in one product.
- **Candidate page type:** "OurHome alternative" / "best chore apps 2026" comparison page.
- **Conversion potential:** High — abandonment is a strong switching trigger.

### 2. Cross-device / points sync failures
- **Problem:** The points/rewards system stops syncing between family members' phones; kids' progress disappears, killing motivation.
- **Evidence (paraphrased, aggregated via WebSearch, accessed 2026-09-15):** *"the points system stopped syncing between phones, with kids losing motivation when their progress disappeared"*; also cited: requires active internet connection to sync tasks/points, poor connectivity causes "white screen" errors.
- **User type:** Parents running an allowance/reward system for multiple kids.
- **Intent:** Troubleshooting ("OurHome not syncing") → alternative-seeking.
- **Related Kinrows capability:** Server-validated chores/allowance ledger with non-punitive streak; payout ledger scoped per household.
- **Candidate page type:** Troubleshooting-style blog post that pivots to comparison ("Fix OurHome sync issues, or switch to an app that just works").
- **Conversion potential:** Medium-high.

### 3. Confusing rebrand / duplicate listings
- **Problem:** Multiple "OurHome" apps (original chores app, "OurHome by Elusios") with different developers, ratings, and feature sets create confusion about which is legitimate/current.
- **Evidence:** App Store search returns both id 879717020 (delisted) and id 6753957205 "OurHome by Elusios" (4.1★, described as shopping-list + task management, not the classic chores/allowance product).
- **User type:** New searchers trying to find "the" OurHome app.
- **Intent:** Navigational confusion → informational.
- **Related Kinrows capability:** Single stable app identity (Kinrows/com.kinrows.app).
- **Candidate page type:** N/A directly, but useful trust-signal copy ("one app, always up to date").
- **Conversion potential:** Low-medium.
